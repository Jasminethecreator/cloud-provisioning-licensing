# Cloud Provisioning - P2 Licensing in Microsoft Azure's Entra ID

## Objective

Fully provision a user account by assigning a Microsoft Entra ID P2 license.

## Scenario

This lab simulated completing a new employee's account setup by assigning the correct license tier, a required step before certain identity and security features become available to that user.

## Tasks Completed

- Checked Kyle Roberts' account prior to licensing and confirmed no licenses were assigned.
- Located the Microsoft Entra ID P2 license in the Microsoft 365 Admin Center.
- Assigned the Entra ID P2 license to Kyle Roberts.

## What I Learned

This lab showed me that a license has to be assigned deliberately,without it, a user doesn't get access to certain identity and security features, even if their account otherwise looks fully set up.
